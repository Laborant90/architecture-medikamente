**Список проблем текущей архитектуры при работе с данными**

1. Данные пациентов и файлы БД (например 1С) хранятся на одном и том же файловом сервере
2. Отсутствует аудит действий с файлами
3. Отсутствует резервное копирование файлов и БД
4. Отсутствует шифрование (данные хранятся как есть)
5. «1С:Бухгалтерия предприятия». Программа работает в файловом режиме - файловый режим не обеспечивает контроль доступа. 
6. «1С:Торговля и склад». Программа работает в файловом режиме - файловый режим не обеспечивает контроль доступа.
7. Физический сервер с Microsoft Windows Server 2022. На нём настроены Active Directory, DNS, DHCP, LDAP, файловый сервер, Exchange Mail Server. ККМ связаны с сервером через TCP/IP и компоненту 1С по технологии OLE - единая точка отказа, будет более надёжным решением распределить функционал между разными серверами + решение на платной платформе (необходимо оплачивать лицензию и непонятно как обстоят дела с обновлениями).

Меры защиты:

1. При передаче данных между сервисами внутри системы, а также при обмене данными с внешними системами обязательно шифрование при передаче.
2. При необходимости аналитической обработки и формирования отчётности работа должна проводится с обфусцированными и маскированными данными.
3. Хранение медицинской информации и персональных данных в архивах должно проводится с использованием шифрования архива.
