**Список изменений в архитектуре**
1. Необходимо разработать информационную систему (медицинскую информационную систему - МИС), которая обеспечивает функциональность электронного журнала, ведения электронных медицинских карт, обработки информации об анализах.
2. Необходимо обеспечить миграцию данных в МИС из существующих файловых серверов (а позже вывести файловые сервера из эксплуатации)
3. В МИС реализовать микросервисную архитектуру, при этом необходимо в разных БД хранить: 
- электронный журнал и персональные данные клиентов (PostgreSQL) 
- медицинские данные пациентов (карты, данные приёмов, анализы) (Handoop)
4. Необходимо реализовать контроль доступа к МИС путём введения RBAC (используя Keycloak)
5. Данные с СУБД МИС необходимо хранить в шифрованном виде.
6. Обмен данных с внешней системой лаборатории необходимо реализовать по протоколу HTTPS, версия протокола HTTP - HTTP/2. Необходимо, чтобы пациент в личном кабинете МИС привязал аккаунт в лаборатории (внешняя система) и разрешил обмен данными (в таком случае достаточно передавать только идентификатор клиента в лаборатории).
7. Необходимо установить срок, на который хранятся данные в МИС после чего данные удаляются.
8. Для аналитической обработки данные необходимо обезличивать (персональные данные обфусцировать), а также выбирать только необходимые для обработки данные (нужно продумать структуру необходимой для аналитики информации).
