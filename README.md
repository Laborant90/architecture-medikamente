# architecture-medikamente

В папке Task1 размещено решение Задания 1:
1. "Диаграмма потоков данных.xml" отражает существующие потоки данных
2. "Диаграмма потоков данных доработанная.xml" - отражает существующие потоки данных с тегированием данных, а также указанием механизмов защиты данных. 
3. "Список проблем.md" - в файле указаны проблемы текущей архитектуры, таблица со списком данных для защиты и общая информация о мерах защиты.

В папке Task 2 размещено решение Задания 2:
1. "Диаграмма контекста.xml" содержит диаграмму контекста "To-Be". На диаграмму добавлены блоки связанные с аналитической обработкой данных и соблюдением принципов DataPrivacy.
2. "Список изменений.md" содержит список изменений, которые нужно сделать, чтобы достичь результат To-Be.

В папке Task 3 размещено решение Задания 3:
1. "Классификация данных.md" - таблица с классификацией данных
2. "Меры защиты.md" - список предлагаемых мер защиты данных

В папке Task 4 размещено решение Задания 4:
1. "Диаграмма Исикавы.md" - содержит диаграмму "Рыбья кость" с указанием проблем при миграции на новую архитектуру.
2. "Оценка узких мест при миграции.md" - отчёт по выявленным узким местам при миграции
