Меры защиты данных:
1. Внедрить автоматизированный контроль за движением данных на основе тегирования Apache Atlas (так как для хранения данных уже используется Apache Handoop).
2. Внедрить ролевую модель на основе RBAC интегрировать роли с тегированием данных (Keycloak + атрибуты JWT)
3. При передаче данных внутри системы необходимо использовать шифрование TLS версии 1.2
4. При обмене данных с внешней системой лаборатории необходимо использовать HTTPS, версия протокола HTTP - HTTP/2. Необходимо, чтобы пациент в личном кабинете МИС привязал аккаунт в лаборатории (внешняя система) и разрешил обмен данными (в таком случае достаточно передавать только идентификатор клиента в лаборатории).
5. Необходимо использовать шифрование баз данных (шифрование HDFS для Handoop + pgcrypto для Postgres).
